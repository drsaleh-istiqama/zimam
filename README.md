# زِمام (Zimam) — نظام إدارة المؤسسات المالي والإداري

منتج **جدوى للدراسات والتطوير**. تطبيق Frappe يُركَّب فوق **ERPNext v16** (ويُستحسن معه **Frappe HR**) ويضيف ما تحتاجه المؤسسات الثقافية والتعليمية والتدريبية والخيرية، مبنيًّا على ERPNext ومُفصحًا بذلك.

**الاسم:** زِمام الأمر ما يُمسك به ويُضبط؛ و«ديوان الزمام» تاريخيًا هو الديوان المركزي الذي يراجع حسابات الدواوين كلها.

## الوحدات
- **Zimam Core** — الإعدادات، الأذرع الاستثمارية (شركات تابعة بفوترة بينية)، كتالوج الخدمات وطلباتها، أوامر الطباعة (ذراع المطبعة)، الفعاليات والأنشطة الإعلامية، الشؤون القانونية بتنبيهات الانتهاء.
- **Zimam Giving** — الحملات والأسهم والمساهمات الوقفية (قيد يومية آلي + شهادة بالتاريخ الهجري أولًا)، العقارات الوقفية الاستثمارية بعقود إيجار.
- **Zimam Heritage** (نطاق Heritage) — الخزائن الواردة من الأهالي مادةً خامًا بقيمة صفرية ونوع ملكية، المقتنيات، أوامر المعالجة بتكلفة فعلية، الترميم، الرقمنة.
- حزم محجوزة: Education · Training · Charity.

## التهيئة
```
bench --site <site> install-app zimam
bench --site <site> execute zimam.setup.bootstrap.run --kwargs '{"profile": "thakira"}'
```
ملفات التعريف في `zimam/setup/profiles/` (انظر `template.json`).
